# Chahat Raj's website

This repository contains the public website at https://chahatraj.github.io. The live HTML pages stay at the repository root because their URLs and relative asset links depend on that layout. Published assets are in `css/`, `js/`, `fonts/`, `styles/`, `images/`, `data/`, `biasdora-i2t-images/`, `files/`, `slides/`, `posters/`, and `stills/`.

`docs/design/` holds design notes, not pages used by the live site. `website-workbench/` holds local source materials and the editable Papercade prototype. It is excluded from Git and is **not** backed up by this repository or published on the website.

Before publishing changes, inspect the diff and check relative links. The active local branch is `site-redesign`; confirm the GitHub Pages deployment after pushing.
